My App — 400x240

import customtkinter as ctk

# 1. Глобальные настройки темы (до создания окна)
ctk.set_appearance_mode("dark")        # "system", "dark", "light"
ctk.set_default_color_theme("blue")   # "blue", "green", "dark-blue"

class App(ctk.CTk):
    def __init__(self):
        super().__init__()

        self.title("My App")
        self.geometry("400x240")
        self.grid_columnconfigure(0, weight=1)

        self.label = ctk.CTkLabel(self, text="Привет, CustomTkinter!")
        self.label.grid(row=0, column=0, padx=20, pady=(30, 15))

        self.button = ctk.CTkButton(self, text="Нажми меня", command=self.on_click)
        self.button.grid(row=1, column=0, padx=20, pady=10)

    def on_click(self):
        self.label.configure(text="Кнопка нажата! ✨")

if __name__ == "__main__":
    app = App()
    app.mainloop()

Компоновка grid() в CustomTkinter

В CustomTkinter метод grid() — основной инструмент построения адаптивных интерфейсов. Главная ошибка новичков: разместить виджеты в сетке, но забыть настроить weight у строк и столбцов родителя, из-за чего интерфейс не растягивается при изменении размера окна.

Интерактивный симулятор сетки 3×3

Меняйте weight колонок/строк, sticky, columnspan и отступы — наблюдайте за поведением ячейки в реальном времени.

1. Веса сетки (weight) Пропорции растяжения
2. sticky (Позиция в ячейке) "nsew"
3. Объединение и отступы (padx / pady)
Окно приложения (пунктир = границы ячеек grid) Целевой виджет: row=1, col=1
(0,0)
(0,1) Header
(0,2)
(1,0) Nav
Ячейка (1,1)
Целевой виджет sticky="nsew"
(1,2)
(2,0)
(2,1) Footer
(2,2)
Сгенерированный код для вашего макета: 

                        


                    

                

            


            
            

                
                
                

                    
sticky — Компас прилипания

                    

                        По умолчанию виджет располагается строго по центру ячейки и сжимается под размер своего текста. sticky приклеивает его к краям (сторонам света):
                    

                    
                    

                        
"n" (North / Верх)

                        

                            "w" (Лево)
                            "nsew" (Вся ячейка)
                            "e" (Право)
                        

                        
"s" (South / Низ)

                    

                    
    
                        
  • • "ew" — растянуть по горизонтали (для Entry, Button)
    • 
                        
  • • "ns" — растянуть по вертикали (для Sidebar)
    • 
                        
  • • "nsew" — заполнить всю ячейку (для Frame, Textbox)
    • 
                    

                


                
                

                    
padx & pady — Внешние отступы

                    

                        Задают свободное пространство в пикселях вокруг виджета внутри ячейки. Можно передавать одно число или кортеж из двух чисел для асимметричных отступов.
                    

                    
# Одинаковый отступ со всех сторон:
w.grid(row=0, column=0, padx=20, pady=10)

# Разные отступы: (слева, справа) и (сверху, снизу)
w.grid(
    row=1, column=0,
    padx=(20, 5),
    pady=(15, 0)
)

                


                
                

                    
columnconfigure / rowconfigure

                    

                        Вызываются у родительского контейнера (self или frame), чтобы указать, какие столбцы и строки должны забирать свободное место при растяжении окна.
                    

                    
# Колонка 1 заберет всё свободное место:
self.grid_columnconfigure(1, weight=1)

# Настроить сразу несколько колонок:
self.grid_columnconfigure((0, 1), weight=1, uniform="col")

# Минимальная ширина колонки (px):
self.grid_columnconfigure(0, minsize=180)

                


                
                

                    
columnspan & rowspan

                    

                        Позволяют одному виджету занять сразу несколько соседних столбцов или строк (как объединение ячеек в Excel).
                    

                    
# Кнопка на всю ширину 2-х колонок:
submit_btn.grid(
    row=2, column=0,
    columnspan=2,
    sticky="ew"
)

                


                
                

                    
grid_remove() vs grid_forget()

                    

                        Как временно спрятать элемент интерфейса и вернуть его обратно на прежнее место:
                    

                    
# ЛУЧШИЙ СПОСОБ: прячет, но ПОМНИТ row/col/padx
widget.grid_remove()
widget.grid()  # Вернёт точно туда же!

# Стирает все настройки сетки:
widget.grid_forget()

                


                
                

                    
Паттерн: Сайдбар + Рабочая зона

                    

                        Классическая схема десктопного приложения: слева фиксированное меню (weight=0), справа растягиваемый контент (weight=1).
                    

                    
self.grid_columnconfigure(1, weight=1)
self.grid_rowconfigure(0, weight=1)

sidebar.grid(row=0, column=0, sticky="ns")
content.grid(row=0, column=1, sticky="nsew")

Адаптивные цвета и работа с картинками (CTkImage)

            


            

                
                

                    

                        
Адаптивные цвета (light_color, dark_color)

                        

                            Почти любой цветовой параметр в CustomTkinter принимает кортеж из двух HEX-цветов. Библиотека автоматически переключает их при смене системной или пользовательской темы.
                        

                    


                    

                        
                        
card = ctk.CTkFrame(
    master,
    # (Цвет в светлой теме, Цвет в тёмной теме)
    fg_color=("#f1f5f9", "#1e293b"),
    border_color=("#cbd5e1", "#334155"),
    border_width=1,
    corner_radius=14
)

# Динамическое переключение темы по кнопке:
ctk.set_appearance_mode("light") # или "dark"

                    

                


                
                

                    

                        
Чёткие иконки через ctk.CTkImage

                        

                            Обычный PhotoImage мылит картинки на Retina/4K экранах. Используйте CTkImage с библиотекой Pillow (PIL) — она поддерживает масштабирование и разные иконки для светлой и тёмной темы.
                        

                    


                    

                        
                        
from PIL import Image

icon = ctk.CTkImage(
    light_image=Image.open("icon_dark.png"),
    dark_image=Image.open("icon_light.png"),
    size=(20, 20)
)

btn = ctk.CTkButton(master, text="Настройки", image=icon, compound="left")
